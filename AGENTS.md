# Работа над Creative MCP

- Общайтесь на русском; делайте только необходимые проверки.
- Назначение — переносимое развёртывание универсальной среды GIMP + Blender + MCP.
  Peppers.group — пример, не предметная модель ядра.
- До изменений прочитайте README и фактический код. Не считайте локальные файлы
  AAF-Note уже перенесёнными в репозиторий.
- Разделяйте реализованные инструменты, планы и реально выполненные проверки.
- Сохраняйте конфигурацию, другие подключения Codex и пользовательские материалы.
- Не используйте shell=True, не добавляйте MCP-инструменты исполнения произвольного кода.
- Запуск приложений храните массивами аргументов; поддерживайте пути с пробелами.
- STDIO stdout — только MCP; логи — stderr.
- Не подключайте API GIMP 3 к GIMP 2.10. Не импортируйте bpy/GObject GIMP в venv MCP.
- Будущие графические адаптеры должны проверять пути и симлинки, работать только
  в настроенной папке, сохранять новые версии, не перезаписывать исходники.
- Не коммитьте .venv, секреты, личные фото, XCF/BLEND, рендеры и локальные настройки.
- Установщик не должен автоматически менять sandbox Codex, firewall, системный Python,
  глобальные разрешения Flatpak или авторизовываться за пользователя.
- Проверяйте изменённую критическую логику; не устраивайте повторные серии GUI-тестов.
- README обновляйте вместе с поведением. Не заявляйте поддержку ОС проверенной без
  реального запуска на ней.
